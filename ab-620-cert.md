## What's in Each Chapter

### Chapter 1 — Exam Overview & Audience Profile
- Who this exam is for (developer/advanced builder profile)
- Required skills and knowledge areas
- Skills at a glance (exam weights)
- All study resources and useful links

### Chapter 2 — Plan and Configure Agent Solutions (30–35%)
- Planning enterprise integrations, identity, channels, and responsible AI
- Security and governance (DLP, authentication, computer use security)
- Agent flows: create, human-in-the-loop, error handling, monitoring
- Topics: variables, adaptive cards, custom prompts, generative answers, HTTP requests

### Chapter 3 — Integrate and Extend Agents in Copilot Studio (40–45%)
- Enterprise knowledge sources (SharePoint, Dataverse, connectors, Azure AI Search)
- Tools: computer use (CUA), MCP servers, custom connectors, REST APIs
- Multi-agent collaboration (child agents, connected agents, Foundry, Fabric, A2A protocol)
- Azure integration: Azure AI Search + Foundry, model catalog, Application Insights

### Chapter 4 — Test and Manage Agents (20–25%)
- All 7 evaluation methods (General Quality, Compare Meaning, Capability Use, Keyword Match, Text Similarity, Exact Match, Custom)
- Creating and running test sets
- ALM: solutions, environment variables, Power Platform Pipelines
- CI/CD with Azure DevOps and GitHub Actions

### Chapter 5 — Key Technologies & Concepts Reference
- Microsoft Copilot Studio deep dive (components, orchestration modes, licensing)
- Azure AI Foundry (Foundry Agent Service, model catalog, Foundry IQ, Control Plane)
- Power Platform (Dataverse, Power Automate, Power Fx, environments)
- Generative AI concepts (RAG, LLM fundamentals, MCP, A2A, prompt engineering)
- Adaptive Cards (structure, elements, usage in Copilot Studio)
- Integration patterns quick reference
- Full glossary of exam terms
